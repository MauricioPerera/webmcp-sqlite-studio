# Glosario de Términos

- **SQLite WASM**: Motor de base de datos relacional C compilado a bytecode WebAssembly.
- **WebMCP**: Protocolo estándar para exponer herramientas de navegador a agentes de IA.
- **KDD**: Knowledge-Driven Development, metodología de desarrollo guiado por conocimiento auditable.
- **CCDD**: Contract-Driven Development, oráculos formales congelados para agentes.
