# Guía y Niveles de Validación KDD

Este proyecto aplica KDD Nivel 1:
- Contratos CCDD con oráculos congelados (`tests_sha256`).
- Nodos OKF con grafos conexos sin enlaces rotos.
- Scripts con codificación ASCII pura.
- 100% de pruebas unitarias aprobadas en CI/CD.
